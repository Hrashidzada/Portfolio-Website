Piazza Topic Classifier

A multi-class text classification system built from scratch in C++ that predicts the topic of forum posts using the Naive Bayes algorithm.

Description:

  • Implemented a full Naive Bayes classifier in C++17 from first principles, computing prior probabilities and word likelihoods using STL data structures without external ML frameworks.
  • Built a complete training and inference pipeline, including CSV data ingestion, custom tokenization, vocabulary construction, and evaluation on labeled test datasets.
  • Utilized log-probabilities to ensure numerical stability and prevent floating-point underflow when handling large vocabularies.
  • Designed smoothing strategies for unseen words, incorporating fallback probabilities to maintain robust predictions across sparse data.
